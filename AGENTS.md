# OpenCall — Project Rules

The rules for this repo live in **[CLAUDE.md](CLAUDE.md)**. Read that.

This file exists because some tools look for `AGENTS.md` by convention. It is a
pointer rather than a copy on purpose: it *was* a copy, made on 10 August, and
by 15 August it had drifted eighteen lines behind and still pointed readers at
a `Codex.local.md` that no longer exists. Two files stating the same permanent
rules is one file quietly going stale, and these particular rules — what may
never reach a public repo — are the worst ones to read an old version of.
